# ReachEngine — Website Discovery & Architecture Suite

> **Next-Gen Web Architecture Scoping, Visual Style Previewer, Inbound Pricing Engine & Statutory 18% GST Document Generator**

---

## 🌟 Overview

**ReachEngine** is a modern, high-conversion web application designed to streamline website discovery, visual design scoping, client intake, and statutory contract generation for agencies and digital engineering firms. 

Tailored specifically for decision-makers and senior executives (50+ age group), the platform replaces complex technical jargon with plain-English business benefits, visual wireframes, live website style previews, and transparent pricing.

---

## ✨ Key Features

- **🧭 Step 01: Client Discovery & Intake**
  - Brand profiling, page scope range slider (1–25 pages), and functional module selection.
  - Inbound Magnet Pricing Strategy Selector (Ultra-competitive client win rate).

- **👁️ Step 02: Visual Design Style & Page Layout Selector**
  - **3 Distinct Design Aesthetics:**
    - 💎 *Modern Frosted Glass (Glassmorphism)*
    - 🏛️ *Clean Corporate Executive (Minimalist)*
    - 🚀 *Bold High-Impact Luxury (Maximum)*
  - **Live Website Preview Box:** Renders an interactive sample hero section in real-time so business owners see their future website look & feel.
  - **Visual Layout Wireframes:** Pre-built information architecture blocks for Lead Funnels, Corporate B2B Hubs, E-Commerce, SaaS Portals, and Content Hubs.

- **🧾 Step 03: INR Quotation & Statutory 18% GST Engine**
  - All pricing in **Indian Rupees (₹ INR)**.
  - **Dual Payment Gateway Integration (Razorpay & Cashfree Checkout)** included at an unbeatable **₹9,000**.
  - Statutory **18% Goods & Services Tax (GST)** line-itemization under **SAC Code 998314** (*IT Design & Development Services*).
  - **Market Savings Callout:** Displays exact client savings compared to average traditional market agency quotes.
  - **3-Part Milestone Schedule:** 50% Deposit, 25% Midpoint Signoff, 25% Final Pre-Launch Cutover.

- **📄 Step 04: Specification & Legal Contract Exporter**
  - **Product Requirements Document (PRD):** Comprehensive functional & design requirements.
  - **Technical Requirements Document (TRD):** System stack, edge hosting, API webhooks, and security checklist.
  - **Statement of Work (SOW) Contract:** Legal service agreement with statutory 18% GST tax terms, SAC 998314 classification, and GSTIN registration details.
  - **1-Click Copy & Export:** Instant Markdown export for all 3 documents.

- **🎨 Dual Theme System (Light & Dark)**
  - **☀️ Light Mode:** Crisp Frost & Mint Teal (`#ffffff` background, `#0f172a` text, `#0d9488` teal accents).
  - **🌙 Dark Mode:** Obsidian Titanium (`#090a0f` space background, silver contrast panels).
  - **💻 System Sync:** Auto-detects operating system display preferences.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v18.0 or higher
- npm or yarn

### Installation & Launch

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/client-outreach-app.git
   cd client-outreach-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)
